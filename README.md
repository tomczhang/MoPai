# 墨排

把 Markdown 编辑器与公众号排版机合成一个本地写作工作台。

## 启动

```bash
node server.js
```

打开 <http://localhost:8765>。

直接打开 `index.html` 也能编辑、预览和复制；通过本地服务打开时，额外支持调用 `cli-config.json` 中的 Agent CLI 执行 AI 一键排版。

## 核心能力

- Markdown 实时编辑、自动保存、撤销/重做与快捷键
- `.md` 导入、Markdown / 公众号 HTML 导出
- 公众号行内样式与区块组件全部集中在顶部工具栏
- 鼠标框选行列插入表格，无需手写 Markdown 表格源码
- 图片支持线上 URL、本地选择、拖拽上传与编辑区直接拖入
- 左右双栏按阅读进度双向同步滚动
- 理智蓝、摸鱼绿、石墨黑、赤诚红四套公众号主题
- 手机 / 文章画布双预览，12–20 px 正文字号调节
- AI 只优化排版标记，不改写正文
- 输出内联样式与 `<span leaf>`，一键复制富文本到公众号编辑器
- 中文语境半角标点检查与修复
- 默认作者签名与扩展排版组件

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `⌘/Ctrl S` | 保存 |
| `⌘/Ctrl Z` | 撤销 |
| `⌘/Ctrl Shift Z` / `Ctrl Y` | 重做 |
| `⌘/Ctrl B` | 加粗 |
| `⌘/Ctrl I` | 斜体 |
| `⌘/Ctrl U` | 关键词下划线 |
| `⌘/Ctrl K` | 插入链接 |

## AI CLI

编辑 `cli-config.json` 可切换或添加本地 CLI。预设命令支持：

- `{promptFile}`：写入临时提示词文件并替换为路径
- `{prompt}`：直接替换为提示词全文
- 两者都没有：通过 stdin 传入提示词
